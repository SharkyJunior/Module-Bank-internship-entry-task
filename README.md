## Как открыть в Visual Studio 2022

1. Установите [.NET 9 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
2. Откройте файл TicTacToeAPI.sln в Visual Studio 2022
3. Убедитесь, что выбран профиль запуска TicTacToeAPI или Docker
4. Нажмите F5

## Использованные технологии
- Npgsql: подключение к PostgreSQL
